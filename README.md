# Git Analysis for Obsidian

[![GitHub release](https://img.shields.io/github/v/release/Sovinka20/obsidian-git-analysis?style=flat-square)](https://github.com/Sovinka20/obsidian-git-analysis/releases)
[![Obsidian Downloads](https://img.shields.io/badge/Obsidian-%20plugin-purple?style=flat-square&logo=obsidian)](https://obsidian.md/plugins)
[![MIT License](https://img.shields.io/badge/license-MIT-blue.svg?style=flat-square)](LICENSE)

**Git Analysis** — это мощный плагин для [Obsidian](https://obsidian.md), который анализирует Git‑историю ваших Markdown‑файлов и визуализирует статистику изменений: новые файлы, перемещения (с цепочками переименований), удаления, активность по дням и структуру папок.

> ⚠️ **Статус: v0.0.1 — активная разработка.**  
> Плагин работает на **Windows** и использует **Git** для чтения данных из репозитория Obsidian (встроенный API Obsidian не даёт нужных данных и страдает проблемами с кодировкой). Известные глюки и планы — в разделе [Issues](https://github.com/Sovinka20/obsidian-git-analysis/issues).

**Для кого:** писатели, копирайтеры и все, кто работает с большими объёмами текста и AI-инструментами. Плагин помогает видеть прогресс, находить структуру и упрощает навигацию по хранилищу.

## ✨ Возможности

- **Тепловая карта** активности по дням (зелёные квадраты — чем больше новых файлов, тем насыщеннее цвет).
- **Детальный отчёт** за выбранный день: новые, перемещённые и удалённые файлы с размерами в символах.
- **Цепочки перемещений** — отслеживание переименований и перемещений файлов (отображаются оранжевыми стрелками).
- **Сводная статистика** за неделю, месяц, год или произвольный интервал.
- **Дерево папок** с процентным соотношением файлов и символов.
- **Экспорт отчёта** в Markdown‑файл.
- **Полноэкранный режим** для удобного просмотра.
- **Поддержка светлой и тёмной темы** Obsidian.
- **Интерфейс на русском и английском** языках (переключается в настройках).

## 🚀 Установка

### Вручную (текущий способ)

1. Скачайте последнюю версию из [релизов](https://github.com/Sovinka20/obsidian-git-analysis/releases).
2. Распакуйте архив в папку `.obsidian/plugins/git-analysis/` вашего хранилища.
3. Перезагрузите Obsidian и активируйте плагин в настройках.

### Через Community Plugins (планируется)

Публикация в каталоге Community Plugins пока в планах. Как только появится — обновлю раздел.

## 📋 Использование

1. Нажмите на иконку **Git Analysis** (📊) на левой панели или выполните команду **Open Git Analysis** из палитры команд (`Ctrl/Cmd+P`).
2. Нажмите кнопку **🚀 Запустить анализ Git** — плагин соберёт историю коммитов для всех `.md`.файлов.
3. После завершения анализа вы увидите:
   - **Тепловую карту** — клик по ячейке показывает отчёт за день.
   - **Дерево папок** — текущее распределение файлов и символов.
   - **Детальный отчёт** с фильтрацией по датам (Сегодня, Неделя, Месяц, Весь объём, произвольный интервал).
4. Используйте кнопку **📄 Выгрузить в файл**, чтобы сохранить текущий отчёт в виде Markdown‑файла в хранилище.

## 🛠 Требования

- **Obsidian** версии **0.15.0** или выше.
- **Git** должен быть установлен в системе и доступен из командной строки (проверьте командой `git --version`).
- Хранилище должно быть инициализировано как Git-репозиторий (`git init`) и должно иметь историю коммитов.
- **Desktop only** — мобильная версия пока не поддерживается.

---

## 🧠 Как это работает

Плагин не использует встроенный API Obsidian (он не даёт нужных данных и страдает проблемами с кодировкой). Вместо этого он читает **историю Git-репозитория** через `git log` и `git show`: парсит коммиты по `.md`-файлам, обрабатывает статусы `A` (добавлен), `R` (переименован), `D` (удалён), строит карту перемещений и считает символы в каждом файле. Это даёт больше данных и работает стабильнее с кодировками.
